# Exam Prep Platform

A web-based exam preparation platform built with Next.js where students can register, solve practice questions by subject and topic, and stay updated with the latest exam-related news.

## Live Demo

🔗 [https://kpss-beige.vercel.app/](https://kpss-beige.vercel.app/)

## Features

- 👤 User authentication & membership system
- - 📚 Subject and topic-based question practice
  - - 📰 Real-time exam news & updates feed
    - - 📱 Clean, responsive UI
     
      - ## Tech Stack
     
      - - **Next.js** (React)
        - - **TypeScript**
          - - **Tailwind CSS**
            - - **Vercel** (deployment)
             
              - ## Getting Started
             
              - ```bash
                npm install
                npm run dev
                ```

                Open [http://localhost:3000](http://localhost:3000) to view the app.
